# День 4: Строки (Strings)

Текстовые данные в Python называются `string`. Строки пишутся в кавычках (' ' или " ").

## Создание строк
```python
first_name = 'Myrat'
last_name = "Turkmen"
greeting = 'Привет, Мир!'
```

## Экранирование
- `\n` - Перенос на новую строку
- `\t` - Табуляция (пробел)

## Форматирование (f-строки)
- `f"..."` - Подстановка переменных в строку.

## Срезы строк (Slicing)
- `string[start:stop:step]` - Извлечение части строки по индексам.

## Основные методы строк
- `.upper()`, `.lower()`, `.capitalize()`, `.strip()`, `.replace()`, `.split()`
