# День 1: Введение в Python и основные концепции

В этом уроке вы узнаете о языке программирования Python, принципах его работы и базовых типах данных.

---

## 1. Что такое Python?
Python — это чистый, легкий для чтения и высокоуровневый язык программирования. Он используется в веб-разработке, искусственном интеллекте, анализе данных и автоматизации.

---

## 2. Основные типы данных (Data Types)

| Тип данных | Название | Пример | Описание |
| :--- | :--- | :--- | :--- |
| **Integer** | Целое число | `10`, `-5` | Целые числа |
| **Float** | Число с плавающей точкой | `3.14`, `0.5` | Дробные числа |
| **String** | Строка | `"Привет"`, `'Python'` | Текст в двойных или одинарных кавычках |
| **Boolean** | Логический тип | `True`, `False` | Значения Истина или Ложь |
| **List** | Список | `[1, 2, 3]` | Упорядоченная изменяемая коллекция |
| **Tuple** | Кортеж | `(1, 2, 3)` | Неизменяемый список |
| **Dictionary** | Словарь | `{"key": "value"}` | Пара ключ-значение |
