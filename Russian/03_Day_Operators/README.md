# День 3: Операторы и их глубокая архитектура

В Python операторы служат не только для арифметики, но и являются ключевыми инструментами управления логическим потоком и объектами.

---

## 1. Арифметические операторы (Arithmetic Operators)

| Оператор | Название | Пример | Описание |
| :--- | :--- | :--- | :--- |
| `+` | Сложение | `a + b` | Конкатенация для строк |
| `-` | Вычитание | `a - b` | Разность чисел |
| `*` | Умножение | `a * b` | Дублирование строк (`"A"*3` -> `"AAA"`) |
| `/` | Деление | `a / b` | Всегда возвращает `float` (`6 / 2` -> `3.0`) |
| `//` | Целочисленное деление | `a // b` | Отбрасывает дробную часть (`7 // 2` -> `3`) |
| `%` | Остаток от деления | `a % b` | Полезно для проверки четности/нечетности |
| `**` | Возведение в степень | `a ** b` | Вычисляет $a^b$ (`2 ** 3` -> `8`) |

---

## 2. Операторы сравнения (Comparison Operators)

Результат сравнения всегда является **`True`** или **`False`** (Boolean).

* `==` Равно
* `!=` Не равно
* `>` Больше
* `<` Меньше
* `>=` Больше или равно
* `<=` Меньше или равно

---

## 3. Логические операторы (Logical Operators)

- **`and`**: Возвращает `True`, если все условия истинны.
- **`or`**: Возвращает `True`, если хотя бы одно условие истинно.
- **`not`**: Инвертирует результат (`not True` -> `False`).

> **Ленивые вычисления (Short-circuit Evaluation):**
> Если результат выражения `and` или `or` понятен по первому условию, Python не вычисляет оставшиеся. Это оптимизирует скорость работы.

---

## 4. Операторы тождественности и принадлежности

- **`is` против `==`**: 
  - `==` сравнивает **значения** объектов.
  - `is` сравнивает **адреса объектов в памяти (RAM)**.
- **`in` / `not in`**: Проверяет наличие элемента в коллекции (List, String, Tuple).

---

## 5. Побитовые операторы (Bitwise Operators)

Позволяют работать с числами на уровне двоичных битов (`0` и `1`):
- `&` (AND), `|` (OR), `^` (XOR), `~` (NOT), `<<` (Сдвиг влево), `>>` (Сдвиг вправо).

---

## 6. Приоритет операторов (Operator Precedence)

Порядок выполнения операций в Python:
1. `()` - Скобки
2. `**` - Возведение в степень
3. `+x`, `-x`, `~x` - Унарные операторы
4. `*`, `/`, `//`, `%` - Умножение и деление
5. `+`, `-` - Сложение и вычитание
6. `<<`, `>>` - Битовые сдвиги
7. `&`, `^`, `|` - Побитовые операции
8. Операторы сравнения (`==`, `is`, `in`)
9. `not`, `and`, `or` - Логические операторы
