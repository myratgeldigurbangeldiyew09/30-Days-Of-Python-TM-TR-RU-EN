# День 5: Списки (Lists)

Списки (`list`) в Python используются для хранения нескольких элементов в одной переменной. Списки являются изменяемыми (mutable).

## Создание списка
```python
fruits = ['яблоко', 'банан', 'апельсин']
numbers = [1, 2, 3, 4, 5]
```

## Индексация и срезы (Indexing & Slicing)
- `fruits[0]` - Получает первый элемент
- `fruits[-1]` - Получает последний элемент
- `fruits[0:2]` - Получает первые два элемента

## Основные методы списков
- `.append()` - Добавляет элемент в конец
- `.insert()` - Добавляет элемент по указанному индексу
- `.remove()` - Удаляет элемент по значению
- `.pop()` - Удаляет и возвращает элемент по индексу
- `.sort()` - Сортирует список
- `.reverse()` - Разворачивает список
