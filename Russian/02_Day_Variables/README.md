# День 2: Переменные и встроенные функции

В этом уроке вы узнаете, как создавать переменные в Python, правила их именования и как использовать основные встроенные функции.

---

## 1. Что такое переменная?
Переменная — это контейнер для хранения данных в памяти компьютера.

### Правила именования:
- Может содержать только буквы, цифры и символ подчеркивания (`_`).
- Не может начинаться с цифры (`1name` — ошибка, `name1` — верно).
- Регистрозависима (`age` и `Age` — разные переменные).
- В Python принято использовать стиль **snake_case** (`first_name`, `user_age`).

---

## 2. Основные встроенные функции

| Функция | Описание | Пример |
| :--- | :--- | :--- |
| `print()` | Выводит данные на экран | `print("Привет")` |
| `len()` | Возвращает длину объекта | `len("Python")` -> `6` |
| `type()` | Возвращает тип данных | `type(10)` -> `<class 'int'>` |
| `str()`, `int()`, `float()` | Приведение типов (Casting) | `str(10)` -> `"10"` |
| `input()` | Получает ввод от пользователя | `input("Имя: ")` |
