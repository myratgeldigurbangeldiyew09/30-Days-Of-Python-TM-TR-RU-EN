# 5. Gün: Listeler (Lists)

Python'da listeler (`list`) birden fazla veriyi tek bir değişkende saklamak için kullanılır. Listeler değiştirilebilir (mutable) yapılardır.

## Liste Oluşturma
```python
fruits = ['elma', 'muz', 'portakal']
numbers = [1, 2, 3, 4, 5]
```

## İndeksleme ve Dilimleme (Indexing & Slicing)
- `fruits[0]` - İlk elemanı alır
- `fruits[-1]` - Son elemanı alır
- `fruits[0:2]` - İlk iki elemanı alır

## Temel Liste Metotları
- `.append()` - Sona eleman ekler
- `.insert()` - Belirli bir indekse eleman ekler
- `.remove()` - Elemanı değerine göre siler
- `.pop()` - İndekse göre siler ve döndürür
- `.sort()` - Listeyi sıralar
- `.reverse()` - Listeyi tersine çevirir
