# 4. Gün: Metinler (Strings)

Python'da metin verileri `string` olarak adlandırılır. Metinler tırnak işareti (' ' veya " ") içinde yazılır.

## Metin Oluşturma
```python
first_name = 'Myrat'
last_name = "Turkmen"
greeting = 'Merhaba Dünya!'
```

## Kaçış Karakterleri
- `\n` - Yeni satıra geç
- `\t` - Tab (boşluk) bırak

## String Formatting (f-string)
- `f"..."` - Değişkenleri metin içinde kolayca yazmak.

## String Slicing (Dilimleme)
- `string[start:stop:step]` - İndeks ile metin dilimleme.

## Temel String Metotları
- `.upper()`, `.lower()`, `.capitalize()`, `.strip()`, `.replace()`, `.split()`
