# 1. Gün: Python'a Giriş ve Temel Kavramlar

Bu derste Python programlama dili, çalışma mantığı ve temel veri tipleri hakkında bilgi edineceksiniz.

---

## 1. Python Nedir?
Python; temiz, okuması kolay ve yüksek seviyeli bir programlama dilidir. Web geliştirme, yapay zeka, veri analizi ve otomasyon gibi birçok alanda kullanılır.

---

## 2. Temel Veri Tipleri (Data Types)

| Veri Tipi | Adı | Örnek | Açıklama |
| :--- | :--- | :--- | :--- |
| **Integer** | Tam Sayı | `10`, `-5` | Tam sayılar |
| **Float** | Ondalıklı Sayı | `3.14`, `0.5` | Ondalıklı sayılar |
| **String** | Metin | `"Merhaba"`, `'Python'` | Çift veya tek tırnak içindeki metinler |
| **Boolean** | Mantıksal | `True`, `False` | Doğru veya Yanlış değerler |
| **List** | Liste | `[1, 2, 3]` | Sıralı ve değiştirilebilir koleksiyon |
| **Tuple** | Demet | `(1, 2, 3)` | Değiştirilemez liste |
| **Dictionary** | Sözlük | `{"key": "value"}` | Anahtar-değer çifti |

---
