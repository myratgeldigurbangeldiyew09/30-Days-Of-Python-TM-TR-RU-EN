# 2-nji Gün: Üýtgeýänler we Içki Funksiýalar

Şu sapakda siz Python-da üýtgeýänleri (variables) nädip döretmelidigini, at berliş düzgünlerini we taýýar içki funksiýalary (built-in functions) öwrenersiňiz.

---

## 1. Üýtgeýän näme?
Üýtgeýän — kompýuteriň ýatda saklaýjy meýdanynda maglumatlary saklamak üçin ulanylýan konteýnerdir.

### At berliş düzgünleri (Naming Rules):
- Ýazgy diňe harp, san we aşaky çyzyk (`_`) bilen başlap biler.
- San bilen başlap bilmez (`1name` ýalňyş, `name1` dogry).
- Ululy-kichili harplara duýgurdyr (`age` we `Age` aýry zatlar).
- Python-da köplenç **snake_case** ulanylýar (`first_name`, `user_age`).

---

## 2. Esasy Içki Funksiýalar (Built-in Functions)

| Funksiýa | Düşündiriş | Mysal |
| :--- | :--- | :--- |
| `print()` | Ekrana maglumat çykarýar | `print("Salam")` |
| `len()` | Maglumatyň uzynlygyny çykarýar | `len("Python")` -> `6` |
| `type()` | Maglumatyň görnüşini görkezýär | `type(10)` -> `<class 'int'>` |
| `str()`, `int()`, `float()` | Maglumat görnüşini üýtgetýär (Casting) | `str(10)` -> `"10"` |
| `input()` | Ulanyjydan maglumat alýar | `input("Adyňyz: ")` |
