# 5-nji Gün: Sazlaşykly Sanawlar (Lists)

Python-da sanawlar (`list`) birnäçe maglumaty birden saklamak üçin ulanylýar. Sanawlar üýtgedilip bilinýändir (mutable).

## Sanaw döretmek
```python
fruits = ['alma', 'banan', 'oranj']
numbers = [1, 2, 3, 4, 5]
```

## Indekslemek we Kesip almak (Indexing & Slicing)
- `fruits[0]` - Birinji elementi alýar
- `fruits[-1]` - Soňky elementi alýar
- `fruits[0:2]` - Ilki iki elementi alýar

## Esasy Sanaw Metodlary
- `.append()` - Soňuna element goşmak
- `.insert()` - Belgilendirilen indekse element goşmak
- `.remove()` - Elementi ady boýunça pozmak
- `.pop()` - Indeks boýunça pozmak we yzyna bermek
- `.sort()` - Sanawy tertiplemek
- `.reverse()` - Sanawy tersine öwürmek
