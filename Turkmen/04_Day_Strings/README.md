# 4-nji Gün: Tekstler (Strings)

Python-da tekst maglumatlary `string` diýlip atlandyrylýar. Tekstler gubka (' ' ýa-da " ") arasynda ýazylýar.

## Tekst döretmek
```python
first_name = 'Myrat'
last_name = "Turkmen"
greeting = 'Salam, Dünýä!'
```

## Escape Yşaratlary
- `\n` - Täze hatara geçmek
- `\t` - Tab (boşluk) goýmak

## String Formatting (f-string)
- `f"..."` - Üýtgeýänleri tekstiň içinde aňsat ýazmak.

## String Slicing (Kesip almak)
- `string[start:stop:step]` - Indeks boýunça böleklerini almak.

## Esasy String Metodlary
- `.upper()`, `.lower()`, `.capitalize()`, `.strip()`, `.replace()`, `.split()`
