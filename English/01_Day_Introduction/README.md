# Day 1: Introduction to Python & Basic Concepts

In this lesson, you will learn about the Python programming language, how it works, and basic data types.

---

## 1. What is Python?
Python is a clean, easy-to-read, and high-level programming language. It is widely used in web development, AI, data science, and automation.

---

## 2. Basic Data Types

| Data Type | Name | Example | Description |
| :--- | :--- | :--- | :--- |
| **Integer** | Whole number | `10`, `-5` | Integer numbers |
| **Float** | Decimal number | `3.14`, `0.5` | Floating-point numbers |
| **String** | Text | `"Hello"`, `'Python'` | Text wrapped in quotes |
| **Boolean** | Logical | `True`, `False` | True or False values |
| **List** | List | `[1, 2, 3]` | Ordered mutable collection |
| **Tuple** | Tuple | `(1, 2, 3)` | Immutable list |
| **Dictionary** | Dict | `{"key": "value"}` | Key-Value pairs |
