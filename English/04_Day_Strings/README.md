# Day 4: Strings

Text data in Python is called a `string`. Strings are written inside quotes (' ' or " ").

## Creating Strings
```python
first_name = 'Myrat'
last_name = "Turkmen"
greeting = 'Hello, World!'
```

## Escape Sequences
- `\n` - New line
- `\t` - Tab (space)

## String Formatting (f-string)
- `f"..."` - Insert variables into string.

## String Slicing
- `string[start:stop:step]` - Extract parts of a string using indices.

## Basic String Methods
- `.upper()`, `.lower()`, `.capitalize()`, `.strip()`, `.replace()`, `.split()`
