# Day 2: Variables & Built-in Functions

In this lesson, you will learn how to declare variables in Python, variable naming conventions, and common built-in functions.

---

## 1. What is a Variable?
A variable is a container for storing data values in memory.

### Naming Conventions:
- Can contain letters, numbers, and underscores (`_`).
- Cannot start with a number (`1name` is invalid, `name1` is valid).
- Case-sensitive (`age` and `Age` are different variables).
- Use **snake_case** convention in Python (`first_name`, `user_age`).

---

## 2. Common Built-in Functions

| Function | Description | Example |
| :--- | :--- | :--- |
| `print()` | Prints output to the console | `print("Hello")` |
| `len()` | Returns the length of an object | `len("Python")` -> `6` |
| `type()` | Returns data type | `type(10)` -> `<class 'int'>` |
| `str()`, `int()`, `float()` | Converts data types (Casting) | `str(10)` -> `"10"` |
| `input()` | Gets user input | `input("Name: ")` |
